# 4900 Game Dev Project

A first-person, story-driven shooter with horror elements, built in Unreal Engine 5.8.

> **Status:** early development. No systems are complete yet.


## About

The story comes first. Horror is used for atmosphere at specific moments instead of running through the whole game, so it should be enjoyable for players who don't normally gravitate towards horror.

The final title has not been decided. "Moon" is a temporary name used in the project files.

## Tech

- **Engine:** Unreal Engine 5.8
- **Language:** C++ with Blueprints
- **IDE:** JetBrains Rider

### C++ and Blueprint split

Core gameplay logic is written in C++. Visual work, such as UI layout and presentation, is done in Blueprints.
